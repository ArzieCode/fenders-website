# Arsip Vite sebelumnya

Direktori ini menyimpan 21 file proyek Vite/React terdahulu **tanpa perubahan isi**. Aplikasi aktif berada di `src/app/` dan dijalankan dengan Next.js melalui `npm run dev`. Arsip ini tidak dibangun, tidak di-deploy, dan dependensinya tidak dipasang oleh `package.json` akar. Jangan menjalankan `vite.config.ts` dari sini untuk melihat website terbaru.
